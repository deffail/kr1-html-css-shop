# Учебный интернет-магазин

Учебный frontend-проект интернет-магазина, выполненный в рамках дисциплины
«Фронтенд и бэкенд разработка».

## Демо

Проект опубликован на GitHub Pages:

**[Открыть интернет-магазин](https://deffail.github.io/kr1-html-css-shop/)**

## Возможности

- навигация по разделам страницы;
- каталог популярных товаров;
- адаптивная сетка карточек на CSS Grid;
- горизонтальное меню на Flexbox;
- БЭМ-именование элементов карточек;
- логотип с абсолютным позиционированием;
- фиксированная кнопка возврата к началу страницы;
- модальное окно оформления заявки;
- проверка заполнения полей формы;
- сообщение об успешной отправке.

## Используемые технологии

- HTML5 — семантическая структура страницы;
- CSS3 — оформление, Flexbox, Grid и позиционирование;
- JavaScript — открытие модального окна и обработка формы;
- Git и GitHub — хранение истории разработки;
- GitHub Pages — публикация проекта.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

### Flexbox и CSS Grid

Flexbox используется для горизонтального расположения пунктов меню. CSS Grid
формирует сетку карточек товаров и автоматически распределяет доступную ширину.

### БЭМ

Для элементов карточки используются классы:

- `product-card__title`;
- `product-card__description`;
- `product-card__price`;
- `product-card__button`.

### Позиционирование

- `position: relative` задаёт шапку как основу позиционирования;
- `position: absolute` размещает логотип внутри шапки;
- `position: fixed` закрепляет кнопку «Наверх» в углу окна.

## Как запустить проект

Скачайте репозиторий и откройте файл `index.html` в браузере. Установка
дополнительных программ и зависимостей не требуется.
